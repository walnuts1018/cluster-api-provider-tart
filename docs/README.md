# Tartドキュメント

TartはTalos Linux専用のCluster API Providerです。対応versionはTalos 1.14.x、Kubernetes workload cluster 1.36.x/1.37.x、Cluster API 1.14.1以降の1.14 minor lineです。

## 利用者向けドキュメント

導入手順は[Talos Linux導入](installation/talos.md)を参照してください。実機E2Eによる受け入れ確認は未実施であり、実機での動作保証はまだありません。support policyの詳細は[開発者向けドキュメント](development/README.md)を参照してください。

## 開発者向けドキュメント

達成すべき要件・ユースケースと非目標は[開発者向けドキュメント](development/README.md)を、設計・実装レビューの着眼点は[`.agents/skills/`](../.agents/skills)を参照してください。
