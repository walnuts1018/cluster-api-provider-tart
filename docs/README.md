# Tartドキュメント

TartはTalos Linux専用のCluster API Providerです。

## 利用者向けドキュメント

導入手順は[Talos Linux導入](installation/talos.md)を参照してください。実機E2Eによる受け入れ確認は未実施であり、対応version matrixは未定義です。現時点のreleaseは理論上動作する実装を提供するものであり、実機での動作保証はまだありません。

## 開発者向けドキュメント

達成すべき要件・ユースケースと非目標は[開発者向けドキュメント](development/README.md)を、設計・実装レビューの着眼点は[`.agents/skills/`](../.agents/skills)を参照してください。
